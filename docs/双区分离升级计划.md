### 2. 牛马状态动画

| 状态 | 动画 | 说明 |
|------|------|------|
| 空闲 | 🐮 睡觉 💤 | 无任务，右侧折叠 |
| 开工 | 🐮 伸懒腰 🚀 | 收到任务，准备开始 |
| 工作中 | 🐮 敲键盘 ⌨️ | 任务执行中，日志滚动 |
| 遇到问题 | 🐮 挠头？🤔 | 卡住了，需要帮助 |
| 完成 | 🐮 欢呼 🎉 | 任务完成，展示结果 |

### 3. 小梦"插嘴"规则

**触发时机：**

| 右边状态 | 小梦可能说的话 |
|----------|---------------|
| 开工 | "哟，小伙伴动起来了~" |
| 工作中 | "它正埋头苦干呢~" |
| 卡住了 | "哎呀，好像卡壳了，我催催它🔧" |
| 完成 | "搞定啦！效率还不错嘛~" |

**规则：**
- 只在状态变化时检查是否插嘴
- 30% 概率真正插嘴，70% 保持安静
- 台词 80% 预设 + 20% AI 生成

### 4. 一键收起

**用户点击"让它退下吧"：**
1. 牛马播放收拾东西 → 挥手动画
2. 工作区 slide-out 滑出
3. 小梦说："小伙伴已下班，老板还有什么吩咐？"

## ⚙️ 技术方案

### 1. 双 Agent 架构

```
用户输入
    │
┌───┴───────────────────────────────┐
│                                    │
▼                                    ▼
┌──────────┐                 ┌──────────┐
│ 闲聊 Agent │                 │ 工作 Agent│
│  (小梦)   │                 │  (牛马)   │
│            │                 │            │
│ 角色:      │                 │ 角色:      │
│ 陪伴+调侃  │                 │ 执行+汇报  │
└──────────┘                 └──────────┘
```

### 2. API 设计

```
POST /api/chat
  body: { message: "你好小梦" }
  → 闲聊 Agent 回复

POST /api/work
  body: { task: "整理这个表格" }
  → 工作 Agent 执行，返回任务ID

GET /api/work/:id/status
  → 返回 { status: "working", progress: 65, logs: [...] }

WebSocket /ws/work
  → 推送工作状态变化（动画驱动）

内部接口:
  POST /api/overseer/check
  body: { workerStatus: "stuck" }
  → 小梦是否要插嘴
```

### 3. 前端状态机

```javascript
const appState = {
  // 左侧闲聊区
  chatMode: 'idle' | 'chatting',
  
  // 右侧工作区
  workerPanel: 'collapsed' | 'expanded',
  workerStatus: 'idle' | 'starting' | 'working' | 'stuck' | 'done',
  workerAnimation: 'sleep' | 'typing' | 'waving' | 'celebrating',
  workerProgress: 0,
  workerLogs: [],
  
  // 当前任务
  currentTask: null,
  taskResult: null
}
```

### 4. 数据结构

```javascript
// 任务对象
const task = {
  id: "uuid",
  description: "整理表格",
  status: "pending" | "running" | "completed" | "failed",
  progress: 0-100,
  logs: [
    { time: "10:30:01", message: "正在读取文件..." },
    { time: "10:30:05", message: "解析数据中..." }
  ],
  result: null | { type: "file", path: "...", preview: "..." },
  createdAt: timestamp,
  completedAt: null | timestamp
}
```

## 📅 开发计划

### Phase 1：界面改造（优先级：高）

| 任务 | 说明 | 预估时间 |
|------|------|----------|
| 布局拆分 | 左右双区布局 | 1天 |
| 工作区折叠/展开动画 | 丝滑过渡效果 | 0.5天 |
| 牛马状态机 | idle/typing/done 三状态切换 | 0.5天 |
| 实时日志滚动 | 工作区日志实时更新 | 1天 |

**交付物：** 静态页面，动画可跑，但无实际后端

### Phase 2：工作 Agent（优先级：高）

| 任务 | 说明 | 预估时间 |
|------|------|----------|
| 工作 Agent prompt | 设计牛马的角色定位 | 0.5天 |
| POST /api/work 接口 | 接收任务、执行、返回 | 2天 |
| 状态推送机制 | WebSocket 推送进度/日志 | 2天 |
| 任务结果展示 | 文件预览/文本结果 | 1天 |

**交付物：** 工作区可以真正执行任务

### Phase 3：闲聊区 + 插嘴（优先级：中）

| 任务 | 说明 | 预估时间 |
|------|------|----------|
| 闲聊 Agent prompt | 保持原有风格 + 增加调侃能力 | 0.5天 |
| 插嘴判断逻辑 | 状态变化 → 是否插嘴 | 1天 |
| 小梦气泡展示 | 动画气泡显示台词 | 1天 |

**交付物：** 两侧开始有"联动"感

### Phase 4：一键收起 + 优化（优先级：低）

| 任务 | 说明 | 预估时间 |
|------|------|----------|
| "让它退下"按钮 | 点击 → 动画 → 收起 | 1天 |
| 牛马下班台词 | "小伙伴已下班..." | 0.5天 |
| 细节打磨 | 动画流畅度、交互细节 | 2天 |

**交付物：** 完整体验

### 工期汇总

| Phase | 任务 | 预估时间 |

| Phase 1 | 界面改造 | 3天 |

## 🔧 技术债务

改造过程中需要考虑：

| 问题 | 解决方案 |
|------|----------|
| 两个 Agent 调用成本翻倍 | 工作区空闲时不调用；插嘴用轻量模型 |
| 共享用户上下文 | 维护一份共享的用户画像（姓名、职业等） |
| 现有代码兼容 | v2.0 工具能力保持原接口，新接口并行 |

## ✅ 验收标准

改造完成后，满足以下条件才算完成：

- [ ] 日常闲聊不受影响（响应速度不增加）
- [ ] 工作区可执行任务并展示结果
- [ ] 牛马状态动画流畅可读
- [ ] 小梦插嘴自然、不打扰
- [ ] "让它退下"动画丝滑
