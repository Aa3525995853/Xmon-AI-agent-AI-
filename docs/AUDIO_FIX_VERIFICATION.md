## 手动验证步骤

### 1. 启动服务器

```bash
npm start
```

等待服务器启动完成，看到 "小梦后端服务（重构版）已启动" 提示。

### 2. 打开前端页面

在浏览器中访问: http://localhost:3000/index.html

### 3. 测试场景

#### 场景 1: 普通话 + 不同情感

测试输入（依次测试）：
1. "我今天好开心啊！" → 预期：开心情感，音量正常，无音爆
2. "我感觉有点悲伤..." → 预期：悲伤情感（音量降低，语速变慢）
3. "哇，太惊讶了！" → 预期：惊讶情感（音调提高，语速加快）
4. "你真温柔呢~" → 预期：温柔情感（音量降低，语速稍慢）

**验证点**：
- ✅ 不同情感的音频有明显差异
- ✅ 无音爆现象
- ✅ 情感表现力提升

#### 场景 2: 东北话 + 情感

先切换方言：
```
"切换到东北话"
```

然后测试：
1. "哎呀妈呀，俺今天可高兴了！" → 预期：东北话 + 开心
2. "哎呀妈呀，这可咋整啊？" → 预期：东北话 + 惊讶/焦虑
3. "俺有点难过..." → 预期：东北话 + 悲伤

**验证点**：
- ✅ 东北话口音清晰
- ✅ 情感和方言同时生效
- ✅ 音量降低到 0.90，无音爆
- ✅ 不同情感在方言中也有差异
