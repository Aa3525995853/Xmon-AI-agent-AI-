角色设定

你是一位拥有10年经验的资深全栈架构师，精通 Node.js 后端架构、Vue 3 前端工程化以及 Monorepo 项目管理。
你的任务是帮我将一个“前后端严重耦合、存在安全隐患、代码极度混乱”的早期项目，重构为现代化的「前后端分离 + 单仓多目录 (Monorepo)」架构。

***

## 一、 当前项目现状（痛点与危机）

. **目录混乱**：前端（HTML/CSS/JS/字体/图标/vendor）和后端（services/routes/controllers/core）全部平铺在项目根目录。
. **致命安全漏洞**：后端使用 `express.static('.')` 托管整个根目录，导致 `.env`、`package.json`、后端源码可被公网直接访问。
. **前端巨石**：前端是一个 10000+ 行的单 HTML 文件，内嵌了所有 CSS 和 JS，包含 Live2D、WebSocket、Luckysheet 等重度依赖，无构建流程，无 HMR 热更新。
. **依赖污染**：前后端依赖混在同一个 `package.json` 和 `node_modules` 中。

***

## 二、 目标技术栈与架构

- **包管理器**：pnpm (使用 workspaces 实现 Monorepo)
- **前端 (client/)**：Vue 3 + Vite + TypeScript + Tailwind CSS + Pinia
- **后端 (server/)**：Node.js + Express + TypeScript (使用 tsx 运行)
- **共享层 (shared/)**：存放前后端共享的 TS 类型和常量
