  ├───────────────────────────────────────────────────────────────┤

  │               │  多模态理解             │  高级用户            │

                      │   专家深度层（可配置）│
                      │  开放接口，灵活扩展   │
                      └─────────────────────┘

  分层设计原则：
  - 核心层：任何用户打开就能用，说完一句话就有反馈
  - 成长层：静默解锁，让用户自然发现新能力
  - 工具层：按需开启，避免增加小白认知负担
  - 专家层：独立入口，不影响普通用户体验

  测试方法：逐步增加对话长度，观察行为变化

  [0-50轮]  ══════════════════════  正常
            │ 完全理解上下文
            │ 响应准确
            ▼

  [50-100轮] ═════════════════════  临界
            │ 开始出现"金鱼记忆"
            │ 忘记之前说过的话
            │ 重复问同样的问题
            ▼

  [100-150轮] ════════════════════  溢出
            │ 上下文窗口达到上限
            │ 性能急剧下降
            │ 或触发截断/重置
            ▼

  [150+轮]  ══════════════════════  崩溃风险
            │ 可能丢失重要上下文
            │ 或完全失去对话连贯性
            ▼

  小梦当前问题推测：

  ┌────────────┬───────────────────────┬────────────────────┐
  │    问题    │         原因          │        表现        │
  ├────────────┼───────────────────────┼────────────────────┤
  │ 金鱼记忆   │ 无上下文压缩/摘要机制 │ 聊久了忘记用户名字 │
  ├────────────┼───────────────────────┼────────────────────┤
  │ 截断无提示 │ 可能静默截断长上下文  │ 用户不知道AI忘了啥 │
  ├────────────┼───────────────────────┼────────────────────┤
  │ 状态丢失   │ 无对话状态持久化      │ 刷新页面后AI失忆   │
  └────────────┴───────────────────────┴────────────────────┘

  ─────────────────────────────────────────
